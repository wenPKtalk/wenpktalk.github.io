*7.4. Conditional Control and Loops*

本节介绍用于[条件语句和循环](../C1-C_intro/1.3-conditionals.html)的 x86 汇编指令。回想一下，条件语句让程序员能根据条件表达式的结果改变程序的执行。编译器把条件语句翻译成修改指令指针（`%rip`）的汇编指令，使其指向一个并非程序顺序中下一个地址的地址。

> This section covers x86 assembly instructions for [conditionals and loops](../C1-C_intro/1.3-conditionals.html). Recall that conditional statements enable coders to modify program execution based on the result of a conditional expression. The compiler translates conditionals into assembly instructions that modify the instruction pointer (`%rip`) to point to an address that is not the next one in the program sequence.
