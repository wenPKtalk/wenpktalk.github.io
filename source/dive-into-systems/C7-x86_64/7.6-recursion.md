*7.6. Recursion*

递归函数是一类特殊的函数，它们调用自身（也称为**自引用**函数，self-referential function）来计算一个值。和非递归的函数一样，递归函数的每次调用都会创建新的栈帧。与标准函数不同的是，递归函数中包含对自身的函数调用。

> Recursive functions are a special class of functions that call themselves (also known as **self-referential** functions) to compute a value. Like their nonrecursive counterparts, recursive functions create new stack frames for each function call. Unlike standard functions, recursive functions contain function calls to themselves.

我们再来看把从 *1* 到 *n* 的正整数加起来的问题。在前面的小节中，我们讨论了完成这项任务的 `sumUp` 函数。[表 1](7.6-recursion.html) 给出了一个相关的函数 `sumDown`，它按相反的顺序（从 *n* 到 *1*）把数加起来，还给出了与之等价的递归版本 `sumr`：

> Let’s revisit the problem of summing up the set of positive integers from *1* to *n*. In previous sections, we discussed the `sumUp` function to achieve this task. [Table 1](7.6-recursion.html) shows a related function called `sumDown` that adds the numbers in reverse (*n* to *1*), and its recursive equivalent `sumr`:

**表 1.** 迭代版本（sumDown）与递归版本（sumr）

*Table 1. Iterative version (sumDown) and recursive version (sumr)*

**迭代版本**

> **Iterative**

```
int sumDown(int n) {
    int total = 0;
    int i = n;
    while (i > 0) {
        total += i;
        i--;
    }
    return total;
}
```

**递归版本**

> **Recursive**

```
int sumr(int n) {
    if (n <= 0) {
        return 0;
    }
    return n + sumr(n-1);
}
```

递归函数 `sumr` 中的基本情况（base case）处理所有小于一的 *n* 值。递归步骤以值 *n-1* 调用 `sumr`，并在返回之前把结果加到 *n* 上。编译 `sumr` 并用 GDB 反汇编，得到如下汇编代码：

> The base case in the recursive function `sumr` accounts for any values of *n* that are less than one. The recursive step calls `sumr` with the value *n-1* and adds the result to *n* prior to returning. Compiling `sumr` and disassembling it with GDB yields the following assembly code:


上面汇编代码的每一行都加上了英文注解。[表 2](7.6-recursion.html) 给出了对应的 `goto` 形式，以及不含 `goto` 语句的 C 程序：

> Each line in the preceding assembly code is annotated with its English translation. [Table 2](7.6-recursion.html) shows the corresponding `goto` form and C program without `goto` statements:

**表 2.** sumr 汇编代码的 C goto 形式及其翻译

*Table 2. C goto form and translation of sumr assembly code*

**C goto 形式**

> **C goto form**

```
int sumr(int n) {
    int result;
    if (n > 0) {
        goto body;
    }
    result = 0;
    goto done;
body:
    result = n;
    result -= 1;
    result = sumr(result);
    result += n;
done:
    return result;
}
```

**不含 goto 语句的 C 版本**

> **C version without goto statements**

```
int sumr(int n) {
    int result;
    if (n <= 0) {
        return 0;
    }
    result = sumr(n-1);
    result += n;
    return result;
}
```

尽管这个翻译乍一看与原来的 `sumr` 函数并不完全相同，但仔细检查就会发现，两个函数确实是等价的。

> Although this translation may not initially appear to be identical to the original `sumr` function, close inspection reveals that the two functions are indeed equivalent.
