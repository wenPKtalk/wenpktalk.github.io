1. 0b01001010 的十进制值是：

    >
    >
    > (0 \* 2<sup>7</sup>)    +    (1 \* 2<sup>6</sup>)    +    (0 \* 2<sup>5</sup>)    +    (0 \* 2<sup>4</sup>)    +    (1 \* 2<sup>3</sup>)    +    (0 \* 2<sup>2</sup>)    +    (1 \* 2<sup>1</sup>)    +    (0 \* 2<sup>0</sup>)
    >
    >   =    0 + 64 + 0 + 0 + 8 + 0 + 2 + 0    =    74

    用十六进制表示是：

    ```
    0100 1010
      4    A  ->  0x4A
    ```

> 1.  0b01001010 in decimal is:
>
>     >
>     >
>     > (0 \* 2<sup>7</sup>)    +    (1 \* 2<sup>6</sup>)    +    (0 \* 2<sup>5</sup>)    +    (0 \* 2<sup>4</sup>)    +    (1 \* 2<sup>3</sup>)    +    (0 \* 2<sup>2</sup>)    +    (1 \* 2<sup>1</sup>)    +    (0 \* 2<sup>0</sup>)
>     >
>     >   =    0 + 64 + 0 + 0 + 8 + 0 + 2 + 0    =    74
>
>     In hexadecimal, it’s:
>
>     ```
>     0100 1010
>       4    A  ->  0x4A
>     ```

2. 把 389 转换为十进制……

    *使用 2 的幂：*

    - 389 中放得下 256，所以 d<sub>8</sub> 应当是 1，还剩 389 - 256 = 133。

    - 133 中放得下 128，所以 d<sub>7</sub> 应当是 1，还剩 133 - 128 = 5。

    - 5 中放不下 64，所以 d<sub>6</sub> 应当是 0。

    - 5 中放不下 32，所以 d<sub>5</sub> 应当是 0。

    - 5 中放不下 16，所以 d<sub>4</sub> 应当是 0。

    - 5 中放不下 8，所以 d<sub>3</sub> 应当是 0。

    - 5 中放得下 4，所以 d<sub>2</sub> 应当是 1，还剩 6 - 5 = 1。

    - 1 中放不下 2，所以 d<sub>1</sub> 应当是 0。

    - 1 中放得下 1，所以 d<sub>0</sub> 应当是 1，还剩 1 - 1 = 0。

      因此，十进制的 389 对应于 **0b110000101**。

      ------------------------------------------------------------------------

      *使用反复除以 2：*

    - 389 是奇数，所以 d<sub>0</sub> 应当是 1。

    - 389 / 2 = 194，是偶数，所以 d<sub>1</sub> 应当是 0。

    - 194 / 2 = 97，是奇数，所以 d<sub>2</sub> 应当是 1。

    - 97 / 2 = 48，是偶数，所以 d<sub>3</sub> 应当是 0。

    - 48 / 2 = 24，是偶数，所以 d<sub>4</sub> 应当是 0。

    - 24 / 2 = 12，是偶数，所以 d<sub>5</sub> 应当是 0。

    - 12 / 2 = 6，是偶数，所以 d<sub>6</sub> 应当是 0。

    - 6 / 2 = 3，是奇数，所以 d<sub>7</sub> 应当是 1。

    - 3 / 2 = 1，是奇数，所以 d<sub>8</sub> 应当是 1。

    - 1 / 2 = 0，所以第九位及以上的所有数位都是 0。

      因此，十进制的 389 对应于 **0b110000101**。

      转换为十六进制：

      ```
      0001 1000 0101
        1    8    5  ->  0x185
      ```

> 2.  Converting 389 to decimal…​
>
>     *Using powers of two:*
>
>     - 256 fits into 389, so d<sub>8</sub> should be a 1. That leaves 389 - 256 = 133.
>
>     - 128 fits into 133, so d<sub>7</sub> should be a 1. That leaves 133 - 128 = 5.
>
>     - 64 does not fit into 5, so d<sub>6</sub> should be a 0.
>
>     - 32 does not fit into 5, so d<sub>5</sub> should be a 0.
>
>     - 16 does not fit into 5, so d<sub>4</sub> should be a 0.
>
>     - 8 does not fit into 5, so d<sub>3</sub> should be a 0.
>
>     - 4 fits into 5, so d<sub>2</sub> should be a 1. That leaves 6 - 5 = 1.
>
>     - 2 fits does not fit into 1, so d<sub>1</sub> should be a 0.
>
>     - 1 fits into 1, so d<sub>0</sub> should be a 1. That leaves 1 - 1 = 0.
>
>       Thus, decimal 389 corresponds to **0b110000101**.
>
>       ------------------------------------------------------------------------
>
>       *Using repeated division:*
>
>     - 389 is odd, so d<sub>0</sub> should be a 1.
>
>     - 389 / 2 = 194, which is even, so d<sub>1</sub> should be a 0.
>
>     - 194 / 2 = 97, which is odd, so d<sub>2</sub> should be a 1.
>
>     - 97 / 2 = 48, which is even, so d<sub>3</sub> should be a 0.
>
>     - 48 / 2 = 24, which is even, so d<sub>4</sub> should be a 0.
>
>     - 24 / 2 = 12, which is even, so d<sub>5</sub> should be a 0.
>
>     - 12 / 2 = 6, which is even, so d<sub>6</sub> should be a 0.
>
>     - 6 / 2 = 3, which is odd, so d<sub>7</sub> should be a 1.
>
>     - 3 / 2 = 1, which is odd, so d<sub>8</sub> should be a 1.
>
>     - 1 / 2 = 0, so any digit numbered nine or above will be 0.
>
>       Thus, decimal 389 corresponds to **0b110000101**.
>
>       Converting to hexadecimal:
>
>       ```
>       0001 1000 0101
>         1    8    5  ->  0x185
>       ```

> **译注**
> 原答案有两处笔误：开头的「把 389 转换为十进制」应为「转换为二进制」；第七步「还剩 6 - 5 = 1」应为 5 - 4 = 1（译文保留了原样，便于对照）。

3. 五进制的 1423 转换为十进制是：

    >
    >
    > (1 \* 5<sup>3</sup>)    +    (4 \* 5<sup>2</sup>)    +    (2 \* 5<sup>1</sup>)    +    (3 \* 5<sup>0</sup>)
    >
    >   =    125 + 100 + 10 + 3    =    238

> 3.  1423 in base 5 converted to decimal is:
>
>     >
>     >
>     > (1 \* 5<sup>3</sup>)    +    (4 \* 5<sup>2</sup>)    +    (2 \* 5<sup>1</sup>)    +    (3 \* 5<sup>0</sup>)
>     >
>     >   =    125 + 100 + 10 + 3    =    238
