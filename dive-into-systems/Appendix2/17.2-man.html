17.2. man and the Unix Manual

Unix 手册页提供了 ls 或 rm 等 Unix 命令、系统调用以及库函数的文档。可以用 Unix 的 man 命令阅读手册页。apropos 命令可以用来搜索与某个主题相关的 Unix 命令和库函数，主题由作为其命令行参数给出的搜索模式提供。许多 Unix 和 C 库的手册页也可以在网上找到，例如 kernel.org 上。

Unix manual pages provide documentation for Unix commands like ls, or rm, of system calls, and of library functions. You can read manual pages using the Unix man command. The apropos command can be used to search for Unix commands and library functions related to a topic supplied by a search pattern given as its command line argument. Many Unix and C library man pages are also available online, such as at kernel.org.

Unix 手册分为几个部分（section）。前三部分最常用。

The Unix manual is divided into several sections. The first three are the most commonly used.

  1. 第 1 部分是可以在命令行上输入的命令（例如 ls）。
  1. Section 1 is for commands that you can enter on the command line (e.g., ls).
  1. 第 2 部分是可以在程序代码中调用的 Unix 系统调用（例如 fork）。
  1. Section 2 is for Unix system calls that you can call from program code (e.g., fork).
  1. 第 3 部分是可以在程序代码中调用的库函数（例如 printf 这样的 C 库函数）。
  1. Section 3 is for library functions that you can call from your program code (e.g., C library functions such as printf).

运行 man 命令可以查看关于某个命令或函数的文档的手册页。手册页在一个名为 less 的程序中打开。在 less 中，输入 q 退出，按空格键向下翻一整页，用方向键一次上下移动一行。还可以用类似 Vim 搜索的 / 语法搜索内容。

Run the man command to view the manual page with documentation about a command or function. The man page is opened in a program named less. You can quit less by typing q, move down a full a page by typing the space bar, or move up and down one line at a time using the arrow keys. You can also search for content using / syntax similar to Vim search.
