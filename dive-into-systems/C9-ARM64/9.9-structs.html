9.9. structs in Assembly

结构体是在 C 中创建数据类型集合的另一种方式。与数组不同，结构体可以把不同的数据类型组合在一起。C 像存放一维数组那样存放 struct，其数据元素（字段）连续存放。

A struct is another way to create a collection of data types in C. Unlike arrays, they enable different data types to be grouped together. C stores a struct like a single-dimension array, where the data elements (fields) are stored contiguously.

Figure 1 shows how the student is laid out in memory. Each ai denotes an offset in memory.

图 1. struct studentT 的内存布局

Figure 1. The memory layout of a struct studentT.

各字段按照声明的顺序在内存中一个挨一个地连续存放。在图 1 中，age 字段被分配在紧跟 name 字段之后的内存位置（字节偏移 a64），后面依次是 grad_yr（字节偏移 a68）和 gpa（字节偏移 a72）字段。这种组织方式使访问字段既节省内存又高效。

Each field is stored contiguously next to one another in memory in the order in which they are declared. In Figure 1, the age field is allocated at the memory location directly after the name field (at byte offset a64) and is followed by the grad_yr (byte offset a68) and gpa (byte offset a72) fields. This organization enables memory-efficient access to the fields.

Figure 3. The correct memory layout for the updated struct studentTM. Byte a63 is added by the compiler to satisfy memory alignment constraints, but it doesn’t correspond to any of the fields.

A64 的对齐策略要求：四字节的数据类型（例如 int）位于四的倍数的地址上，而 64 位的数据类型（long、double 和指针数据）位于八的倍数的地址上。对于 struct，编译器会在字段之间添加空字节作为「填充」（padding），以确保每个字段都满足其对齐要求。例如，在上面代码片段声明的 struct 中，编译器在字节 a63 处添加了一个字节的填充，确保 age 字段从一个四的倍数的地址开始。在内存中正确对齐的值可以在单次操作中被读取或写入，从而提高效率。

A64’s alignment policy requires that four-byte data types (e.g., int) reside at addresses that are a multiple of four, whereas 64-bit data types (long, double, and pointer data) reside at addresses that are a multiple of eight. For a struct, the compiler adds empty bytes as “padding” between fields to ensure that each field satisfies its alignment requirements. For example, in the struct declared in the previous code snippet, the compiler adds a byte of padding at byte a63 to ensure that the age field starts at an address that is at a multiple of four. Values aligned properly in memory can be read or written in a single operation, enabling greater efficiency.
