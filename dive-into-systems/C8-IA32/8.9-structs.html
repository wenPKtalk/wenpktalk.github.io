8.9. structs in Assembly

结构体是在 C 中创建数据类型集合的另一种方式。与数组不同，结构体可以把不同的数据类型组合在一起。C 像存放一维数组那样存放 struct，其数据元素（字段）连续存放。

A struct is another way to create a collection of data types in C. Unlike arrays, structs enable different data types to be grouped together. C stores a struct like a single-dimension array, where the data elements (fields) are stored contiguously.

图 1 展示了 student 在内存中的布局。为了举例，假设 student 从地址 x0 开始。每个 xi 表示某个字段的地址。

Figure 1 shows how student is laid out in memory. For the sake of example, assume that student starts at address x0. Each xi denotes the address of a field.

图 1. student 结构体的内存布局

Figure 1. The memory layout of the student struct

各字段按照声明的顺序在内存中一个挨一个地连续存放。在图 1 中，age 字段被分配在紧跟 name 字段之后的内存位置（字节偏移 x64），后面依次是 grad_yr（字节偏移 x68）和 gpa（字节偏移 x72）字段。这种组织方式使访问字段既节省内存又高效。

The fields are stored contiguously next to one another in memory in the order in which they are declared. In Figure 1, the age field is allocated at the memory location directly after the name field (at byte offset x64) and is followed by the grad_yr (byte offset x68) and gpa (byte offset x72) fields. This organization enables memory-efficient access to the fields.

8.9.1. Data Alignment and structs

图 3. 更新后的 struct studentTM 的正确内存布局。字节 x63 是编译器为满足内存对齐约束而添加的，它不对应任何字段。

Figure 3. The correct memory layout for the updated struct studentTM. Byte x63 is added by the compiler to satisfy memory alignment constraints, but it doesn’t correspond to any of the fields.

IA32 的对齐策略要求：两字节的数据类型（即 short）位于两字节对齐的地址上，四字节的数据类型（int、float、long 和指针类型）位于四字节对齐的地址上，八字节的数据类型（double、long long）位于八字节对齐的地址上。对于 struct，编译器会在字段之间添加空字节作为填充（padding），以确保每个字段都满足其对齐要求。例如，在上面代码片段声明的 struct 中，编译器在字节 x63 处添加了一个字节的空白（即填充），确保 age 字段从一个四的倍数的地址开始。在内存中正确对齐的值可以在单次操作中被读取或写入，从而提高效率。

IA32’s alignment policy requires that two-byte data types (i.e., short) reside at a two-byte-aligned address whereas four-byte data types (int, float, long, and pointer types) reside at four-byte-aligned addresses, and eight-byte data types (double, long long) reside at eight-byte-aligned addresses. For a struct, the compiler adds empty bytes as padding between fields to ensure that each field satisfies its alignment requirements. For example, in the struct declared in the previous code snippet, the compiler adds a byte of empty space (or padding) at byte x63 to ensure that the age field starts at an address that is at a multiple of four. Values aligned properly in memory can be read or written in a single operation, enabling greater efficiency.

译注 · i386 Linux 上 double 的对齐

在 32 位 x86 Linux（i386 System V ABI）上，结构体中的 double 和 long long 字段其实只按 4 字节对齐。译者用 clang -target i386-linux-gnu 检查：struct { char c; double d; } 中 d 的偏移是 4，整个结构体 12 字节；long long 字段同样位于偏移 4。而在 x86-64 Linux 上，同一个结构体中 d 的偏移是 8，大小是 16。所以原文说的「八字节类型位于八字节对齐的地址上」对 x86-64 成立，对 IA32 Linux 的结构体布局并不成立。
