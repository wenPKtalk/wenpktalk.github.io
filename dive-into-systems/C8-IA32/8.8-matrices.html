这段代码中的第一条指令把变量 j 加载到寄存器 %edx 中。编译器用左移（shl）指令把 j 乘以四，并把结果存放在寄存器 %edx 中。然后，编译器把得到的值加到位于 matrix[i] 中的地址上，得到 matrix[i][j] 的地址。

The first instruction in this snippet loads variable j into register %edx. The compiler uses the left shift (shl) instruction to multiply j by four and stores the result in register %edx. The compiler then adds the resulting value to the address located in matrix[i] to get the address of matrix[i][j].

我们再来看图 4，考虑访问 M2[1][2] 的例子。为方便起见，我们在图 5 中重新给出了这张图。

Let’s revisit Figure 4 and consider an example access to M2[1][2]. For convenience, we reproduce the figure in Figure 5.

图 5. 矩阵 M2 在内存中的不连续布局

Figure 5. Matrix M2’s noncontiguous layout in memory

注意，M2 从内存位置 x0 开始。编译器先计算 M2[1] 的地址：把 1 乘以 4（sizeof(int *)），再加到 M2 的地址（x0）上，得到新地址 x4。对这个地址解引用，得到与 M2[1] 关联的地址，即 x36。然后，编译器把下标 2 乘以 4（sizeof(int)），把结果（8）加到 x36 上，得到最终地址 x44。对地址 x44 解引用，得到值 5。果然，图 5 中与 M2[1][2] 对应的元素的值是 5。

Note that M2 starts at memory location x0. The compiler first computes the address of M2[1] by multiplying 1 by 4 (sizeof(int *)) and adding it to the address of M2 (x0), yielding the new address x4. A dereference of this address yields the address associated with M2[1], or x36. The compiler then multiplies index 2 by 4 (sizeof(int)), and adds the result (8) to x36, yielding a final address of x44. The address x44 is dereferenced, yielding the value 5. Sure enough, the element in Figure 5 that corresponds to M2[1][2] has the value 5.
